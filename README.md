# Arrxy Tap

## How do I install these formulae?

`brew install arrxy/tap/<formula>`

Or `brew tap arrxy/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arrxy/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
